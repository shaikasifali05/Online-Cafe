## Online Cafe:
A simple Java console-based Online Cafe program for ordering food and beverages and calculating the total bill.

## Features:
* Display cafe menu
* Select food and beverages
* Enter quantity
* Calculate item total
* View current bill
* Display final bill

## Technologies:
* Java
* Scanner
* Switch-case
* Loops
* Methods
* Variables
